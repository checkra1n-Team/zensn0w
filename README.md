# ZenSn0w

A fictional jailbreak-themed interface simulation with browser-only utilities, an interactive Snowglobe, a local channel feed, and an NCS music panel.

## Run locally

Open `index.html` in a modern browser. The background video, mark, and stylesheet are stored beside the page.

## Features

- Channel posts can be created, edited, and deleted. Posts are stored in that browser's local storage and are not synced to other people or devices.
- Snowglobe controls snowfall density, motion background blur and shade, color profiles, and the globe shake effect.
- The music panel embeds five official NCS YouTube uploads. Select a track to load it. Playback begins after user interaction; a “Playing now” notice follows the player state.
- No jailbreak, account, or device actions are performed.
